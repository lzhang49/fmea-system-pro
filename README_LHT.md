## S9 试产龙头 (新增)

在 S1 等回撤时，S9 提前 1-2 周识别"准龙头"：

| 阶段 | 操作 | 仓位 |
|---|---|---|
| 首板 | 仅观察 | 0% |
| **二板** | 9:30-10:00 区间均价买入 | 5-10% |
| **三板** | 爆量分歧转一致回封加仓 | 15-25% |
| 四板+ | 不介入 | - |

## 启用顺序

| 阶段 | 时间 | 启用 | 目标 |
|---|---|---|---|
| 阶段1 | 当前 → 1周 | S1+S4+S7+S9(10%仓位) | 最小试产，验证信号 |
| 阶段2 | 1周 → 1月 | +S2+S3 | 加入风控，验证回撤 |
| 阶段3 | 1月 → 2月 | +S5+S6 | 信号分级+动态止盈 |
| 阶段4 | 2月+ | +S8 | 黑天鹅应急 |
